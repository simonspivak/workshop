# Сайт курса «ИИ-старт: 4 воркшопа»

Сайт курса из четырёх воркшопов по ИИ. Три страницы:

- `/` — главная: о курсе, четыре воркшопа, как проходит занятие, доступ к инструментам, запись;
- `/workshops` — подробная программа (пока заглушка);
- `/about` — о ведущем, портфолио, контакты.

Сделано на Next.js + Tailwind. Базы данных нет: все тексты лежат в двух файлах.

---

## Как поменять текст

Все тексты сайта — в файле **`content/site.ts`**.

1. Откройте файл на GitHub и нажмите карандаш ✏️ («Edit this file»).
2. Меняйте только текст **внутри кавычек** `"…"`. Кавычки, запятые и скобки не трогайте.
3. Если в тексте нужны кавычки — используйте «ёлочки».
4. Внизу нажмите **Commit changes**. Через минуту-две Vercel сам обновит сайт.

Пример: чтобы поменять заголовок первого экрана, найдите строку
`title: "Четыре занятия, чтобы ИИ стал твоим инструментом",` и замените текст в кавычках.
Строка `titleHighlight` под ней — это слова из заголовка, которые подсвечены жёлтым.
Если их нет в заголовке, подсветки просто не будет.

Чтобы убрать пункт из списка (например, строку про STEAM-программы), удалите строку целиком вместе с запятой в конце.

## Как поменять название курса, контакты и календарь

Всё это — в файле **`content/config.ts`**:

- `courseName` — название курса (в шапке, футере и во вкладке браузера);
- `contacts` — Telegram, Instagram, GitHub и e-mail. Пишите **без @** и без ссылок: `"senyaspivak"`, а не `"@senyaspivak"`;
- `bookingUrl` — ссылка на календарь (см. ниже).

## Как поменять фото

Фото ведущего — файл **`public/senya.jpg`**. Если файла нет, на его месте аккуратная заглушка.

1. На GitHub откройте папку `public`.
2. **Add file → Upload files**, перетащите фото.
3. Назовите файл `senya.jpg` (подойдёт и `senya.png` или `senya.webp`).
4. **Commit changes**.

Лучше квадратное фото, от 800×800 пикселей.

## Картинки

Сгенерированных картинок на сайте нет: вместо них работают шрифт, цвет, мокап чата на первом экране и бегущая строка с инструментами.
Единственная фотография — фото ведущего (см. выше).

Текст чата на первом экране — раздел `hero` → `chat` в `content/site.ts`, список инструментов в бегущей строке — `marquee` там же.

## Как вставить календарь (Google Calendar)

Ссылка на календарь — строка `bookingUrl` в `content/config.ts`. Сайт понимает два вида ссылок:

- **Ссылка для встраивания** (сейчас стоит она) — календарь показан прямо на странице. Как её взять:
  1. Google Calendar → откройте своё расписание встреч (Appointment schedule) → **Поделиться** (Share).
  2. **Встроить на сайт** (Website embed) → **Встроенное расписание** (Inline schedule).
  3. Google покажет код вида `<iframe src="https://calendar.google.com/calendar/appointments/schedules/…?gv=true" …>`.
     Скопируйте **только ссылку** из `src="…"` и вставьте её в `bookingUrl`.
- **Короткая ссылка** `https://calendar.app.google/…` — вместо календаря будет кнопка «Открыть календарь записи», он откроется в новой вкладке.

Если `bookingUrl` пустой, вместо календаря показывается кнопка «Написать в Telegram».

Часы, которые видят люди в календаре, задаются в самом Google Calendar, в настройках расписания встреч (общая доступность и период записи).
Сайт их не меняет. Текст о времени занятий на сайте — строка `schedule` в разделе `booking` файла `content/site.ts`.

## Как подключить Vercel

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. **Add New… → Project**, выберите репозиторий `simonspivak/workshop` → **Import**.
3. Ничего не меняйте: Vercel сам поймёт, что это Next.js. Нажмите **Deploy**.
4. Через минуту сайт будет по адресу вида `workshop-xxx.vercel.app`.
   Свой домен можно подключить в **Settings → Domains**.

Дальше каждое изменение в ветке `main` обновляет сайт автоматически.

## Для разработчика

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # проверка сборки
npm run lint
```

Структура:

- `content/site.ts`, `content/config.ts` — тексты и настройки;
- `app/` — страницы (`page.tsx`, `about/`, `workshops/`);
- `components/` — блоки страниц; `components/ImageSlot.tsx` — картинка или заглушка, если файла нет;
- `app/globals.css` — цвета и шрифты.

Визуальное направление: просто, стильно и понятно зумерам. Светлый фон `#F6F6FB` с лиловым свечением, почти чёрный текст `#0B0B1A`, фиолетовый `#4338F5` для действий, жёлтый `#FFD43B` для «наклеек» и маркера, розовый `#FF8AD1` и лавандовый `#ECEAFF` как акценты.
Шрифты Unbounded (заголовки), Onest (текст) и JetBrains Mono (подписи), все с кириллицей.
Главный визуальный ход — воркшопы как остановки на одной линии маршрута.
Анимации (чат, бегущая строка, отсчёт цифр, появление карточек) выключаются, если в системе включено «уменьшить движение».
