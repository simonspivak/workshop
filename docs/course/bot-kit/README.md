# Забери бота с собой

На курсе бот работает на платформе «ИИ-старт». **После последнего урока он работает ещё 2 недели, потом отключается.** Дату отключения ведущий пишет в общем чате и в последнем письме.

Чтобы бот жил дальше, перенеси его к себе. Это бесплатно и занимает около 30 минут.

## Что взять с платформы

«Мой бот» → «Забери бота с собой» → скопируй **характер** бота: кто он, как говорит, что умеет, чего не делает. Это и есть твой бот. Код можно написать заново за 5 минут, а характер ты придумывал сам.

Если кнопки пока нет, скопируй текст характера из поля «Характер» вручную.

## Что ещё понадобится

| Что | Где взять | Цена |
|---|---|---|
| Токен Telegram-бота | @BotFather. Подойдёт токен бота с курса или новый: `/newbot` | бесплатно |
| Ключ Gemini | [Google AI Studio](https://aistudio.google.com) → Get API key | бесплатный тариф с лимитами |
| Твой chat id | см. ниже | бесплатно |

**Как узнать свой chat id.** Пока бот ещё не подключён к серверу:

1. Напиши своему боту любое сообщение.
2. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, подставив свой токен.
3. Найди `"chat":{"id":123456789` — это число и есть chat id.

Если бот уже подключён к вебхуку, этот адрес вернёт ошибку. Тогда сначала отключи вебхук.

## Путь 1. Вайбкодинг: Google AI Studio или Claude → Google Apps Script

Подходит почти всем: не нужны ни сервер, ни n8n.

1. Открой [`prompt-ai-studio.md`](./prompt-ai-studio.md) и скопируй промпт.
2. Вставь его в Google AI Studio или Claude, а в конец — свой характер.
3. ИИ напишет код и пошаговую инструкцию. Сделай всё по шагам:
   - вставить код на script.google.com;
   - заполнить свойства скрипта;
   - развернуть веб-приложение;
   - запустить `setWebhook()`.
4. Напиши боту. Если что-то не так, отправь ошибку тому же ИИ (в промпте есть готовая фраза).

## Путь 2. n8n

Подходит тем, у кого есть n8n. Облачный n8n платный; бесплатно — только если ставить его на свой компьютер или сервер.

1. n8n → новый workflow → меню «…» → **Import from File** → [`n8n-telegram-bot.json`](./n8n-telegram-bot.json).
2. В узле «Сообщение в Telegram» создай учётные данные **Telegram** с токеном от @BotFather. Выбери их же в узлах «Отправить заявку владельцу», «Ответить» и «Пока только текст».
3. В узле «Мозг: Gemini» создай учётные данные **Google Gemini** с ключом из AI Studio. Если n8n ругается на модель, выбери актуальную Flash-модель Gemini.
4. В узле «Настройки бота»:
   - замени текст `soul` на свой характер;
   - вставь свой chat id вместо `ВСТАВЬ_СВОЙ_CHAT_ID`.
5. Включи workflow (Publish / Active) и напиши боту.

Что делает шаблон:

1. Бот отвечает в характере и помнит последние 10 сообщений.
2. Он собирает заявку, переспрашивает «Всё верно?».
3. После «да» пересылает заявку тебе в Telegram.

## Правила

- **Токен — это ключ от бота.** Не отправляй его в чаты и не вставляй в код. Если токен утёк, получи новый: @BotFather → `/revoke` *(команда из памяти, проверь в меню BotFather)*.
- **Бот честно говорит, что он бот.** Он не собирает лишнего: паспорта, адреса, данные карт.
- **На бесплатном тарифе Gemini переписка может использоваться Google для улучшения моделей** *(по условиям Gemini API для бесплатного тарифа; проверь актуальную версию)*. Не пиши в бота личное.
- **Младше 18.** Gemini API и Telegram в ЕС — с 18 лет. Делай вместе со взрослым на его аккаунте.
- **Шаблон по умолчанию — бот тёти Фиры** из сериала «На масле», который принимает заявки на ханукальный вечер. Замени характер на свой.
